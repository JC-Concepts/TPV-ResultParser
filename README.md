# TPV Parser PWA

Static site for GitHub Pages. Built with React (or Vue) — currently a modern HTML/Tailwind prototype.

## Features
- Dark / Light theme toggle
- Collapsible left sidebar (icons only mode)
- Results and Upload tabs
- Modern gradient buttons

## Local test
```bash
python -m http.server 8000 --directory pwa
```
Or run `run_parser.bat` for parser execution.
